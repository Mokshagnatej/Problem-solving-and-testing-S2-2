# 🚀 Week 1: Core Java & Array Foundations

Welcome to **Week 1** of the Problem Solving and Testing journey! This week lays down a strong foundation in algorithmic thinking and core language features. The focus is divided between **Core Java features** (such as lambda expressions and custom comparators) and **fundamental array manipulation** techniques in **Java**.

---

## 🎯 Learning Objectives & Key Concepts

- **Prefix Sum Arrays:** Utilized in problems like *Find Pivot Index* to optimize repeated range-sum queries from $O(N^2)$ to $O(N)$.
- **Two-Pointer Techniques:** Essential for solving problems like *Squares of a Sorted Array* in optimal $O(N)$ time.
- **Java 8+ Features:** Deep dive into Lambda Expressions and the `Comparator` interface for functional programming and custom sorting logic.
- **Matrix Iteration:** Navigating 2D arrays efficiently as seen in *Richest Customer Wealth*.
